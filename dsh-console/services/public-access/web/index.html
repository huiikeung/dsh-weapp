小程序接入

将下方域名加入微信后台的 request 合法域名，并填入小程序 utils/access-config.js 的 baseUrl。

统一部署的中继地址为同域名的 wss://域名/relay；微信 socket 合法域名只填 wss://域名。公网到期不影响局域网与直连。

通过设备ID绑定管理员

微信服务端核验

让管理员本人打开小程序「设置 → 公网访问」，复制 WX- 开头的设备ID，在这里绑定。统一使用小程序设备ID，不再填写电脑节点ID、OpenID或旧绑定码。请本人在最近 24 小时内打开过设置。

绑定后重新进入小程序设置，即显示「微信身份」与兑换码管理；普通用户不显示微信身份模块。

接入托管电脑节点（可选）

无需开放本机管理端口

仅供需要后台签发限时设备配对的管理员使用。普通用户兑换公网服务后直接扫描自己插件的二维码，无需添加这里的节点。托管模式在电脑端运行 connector.cjs，仅出站请求，不运行远程命令。

区分扫码期限与访问期限

限时配对由电脑端生成：扫码凭据短期、一次性使用，设备访问按所选天数到期。新限时授权可在「限时配对」停用；停用连接器不会撤销设备。未纳入限时管理的旧设备仍在 DSH 网关中管理。

网页与小程序管理员共用签发数据；节点状态由电脑端回传。

分享奖励规则

好友奖励按本次有效人数所在阶梯发放，每人一次，不追溯补发。不同微信不等于不同实体设备。奖励只增加公网服务有效期。

朋友圈凭证审核
