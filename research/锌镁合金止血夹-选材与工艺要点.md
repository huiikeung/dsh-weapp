# 锌镁合金可吸收止血夹：技术要点与原材料选型

> 适用背景：可吸收金属外科闭合夹（血管结扎 / 软组织止血），目标是在体内保持数周闭合功能后逐渐降解吸收。
> 本文是选型与风险梳理，不是产品设计文件；文中数值为文献量级与工程经验值，落地前必须由实测数据替代。
> 编写日期：2026-10-21

---

## 0. 先给结论

1. **先定基体：Zn 基还是 Mg 基，这是第一个分叉点。**
   止血夹最怕的不是"降解不掉"，而是"夹不牢"和"降解太快/太快失效"。
   - 要长期保持夹持力（4 周以上）、厌恶氢气泡、需要影像可见 → **Zn 基 Zn-Mg 低合金**更稳。
   - 只需要短期闭合（2–4 周）、且能接受产氢和更快的降解 → Mg 基 Mg-Zn（±Ca）体系文献更成熟，已有闭合夹研究。

2. **真正的工程难点只有四个**：夹持力随时间衰减（37 ℃ 蠕变/应力松弛）、加工与灭菌造成的性能漂移、杂质带来的局部腐蚀失控、以及与施夹器接触的电偶腐蚀。

3. **原材料选型的核心不是"锌多纯"，而是"杂质谱可控 + 批间可追溯"。** Fe / Ni / Cu 是阴极相，几十 ppm 就能显著加速局部腐蚀；Pb / Cd / As / Hg 是毒理红线。纯度牌号只是入场券，杂质谱和冶金质量（夹杂、气孔、偏析）才是真本事。

## 1. 两种"锌镁合金"别搞混

用户说"锌镁合金"时，可能指完全相反的两个体系，必须先确认：

| 项目 | **Zn 基（Zn-Mg）** | **Mg 基（Mg-Zn，可含 Ca）** |
| --- | --- | --- |
| 基体 | Zn（Zn ≈ 99.9 %） | Mg |
| 典型成分 | Zn-0.02~0.1 Mg（固溶强化）<br>Zn-1~3 Mg（引入第二相） | Mg-1~6 Zn，常加 Ca / Mn / Zr |
| 熔点 | 420 ℃（Zn 419.5 ℃） | 650 ℃ |
| 密度 | 7.14 g/cm³ | 1.74 g/cm³ |
| 弹性模量 | 约 90–105 GPa | 约 45 GPa |
| 抗拉强度 | 150–300 MPa（随加工态） | 200–300 MPa |
| 延伸率 | 5–20 %（低合金固溶态较好，高 Mg 脆） | 10–25 % |
| 体内降解速率（量级） | **0.02–0.2 mm/年**（偏慢） | **0.3–1.5 mm/年**（偏快） |
| 析氢 | 少（但仍会：Zn + 2H₂O → Zn(OH)₂ + H₂↑） | 明显，局部可形成气泡腔 |
| 降解产物 | Zn²⁺、ZnO/Zn(OH)₂ → 体内转为碱式碳酸锌/磷酸锌 | Mg²⁺、Mg(OH)₂、H₂ |
| 主要风险 | 降解过慢导致长期残留；室温再结晶/自然时效；37 ℃ 蠕变 | 产氢、局部碱化、降解过快导致早期失效 |
| 加工性 | 好（挤压/拉拔/轧制成熟），但各向异性强 | 较差（密排六方，室温成形性差） |

**建议**：先把"临床期望的保持时间 + 允许的降解完成时间"写成一个区间，再回来选体系，不要先选材料。

## 2. 由功能反推材料指标（Design Inputs）

止血夹的功能链条是：**张开 → 夹闭 → 保持夹持力 → 组织愈合/血管闭锁 → 缓慢降解 → 完全吸收**。
材料指标应该从链条上倒推：

| 功能需求 | 材料/结构指标 | 建议目标（待验证） |
| --- | --- | --- |
| 夹得住 | 屈服强度 σ0.2、弹性模量 E | σ0.2 ≥ 150–250 MPa |
| 张开不塑变失效 | 最大工作应变 ε_max | ε_max ≤ 0.3–0.5 × 断裂延伸率 |
| 夹持力维持 4 周 | 37 ℃ 应力松弛率 | 1000 h 松弛 ≤ 20–30 % |
| 不早期断裂 | 延伸率、缺口敏感性、表面缺陷 | δ ≥ 8–15 %（按结构定） |
| 按期吸收 | 体外/体内降解速率 | 失重法 0.05–0.2 mm/年（按 3–12 个月窗口调） |
| 影像可见 | 密度/原子序数 | Zn 天然不透X光，是相对聚合物夹的优势 |
| 组织相容 | 杂质谱、表面粗糙度、产物浓度 | 见第 4、6 节 |
| 可经器械递送 | 尺寸一致性、弹性回复、摩擦系数 | 按施夹器通道定 |

> 关键提醒：**夹持力衰减**通常不是"材料强度不够"，而是**应力松弛 + 蠕变 + 降解截面损失**三者叠加。只在拉伸试验上堆强度，解决不了这个问题。

## 3. 十个最容易踩的坑

### 3.1 室温再结晶与自然时效 → 性能自己会变
Zn 的再结晶温度接近室温（同系温度 T/Tm 高），冷加工后的组织在**室温存放期间就会发生回复/晶粒长大**，硬度和强度缓慢下降（文献里低 Mg 含量 Zn-Mg 的"natural aging"就是这一现象）。
**对策**：规定加工后至成品的时间窗口；成品做时效后性能复测；储存温度/湿度受控；把"出厂检验"卡在灭菌前的最终状态。

### 3.2 37 ℃ 蠕变与应力松弛 → 夹持力悄悄掉
Zn 熔点只有 420 ℃，体温 310 K 对应 **T/Tm ≈ 0.44**，属于显著蠕变区间。夹臂长期处于弯曲应力下，会持续松弛。
**对策**：把 37 ℃ 松弛试验作为**选材的一级筛选指标**（不是可选项）；结构上增加有效臂长、降低工作应力；晶粒细化 + 低温去应力退火；必要时用第二相钉扎（但要控腐蚀）。

### 3.3 灭菌方式可能把力学性能改掉
湿热灭菌（121 ℃ / 134 ℃）对 Zn 基合金相当于**人工退火 + 应力释放**，会直接改变夹持力和尺寸；γ 辐照可能引入缺陷并影响降解；EO 灭菌需注意湿气导致的表面腐蚀。
**对策**：灭菌方式在材料定型前就锁定并验证；湿热灭菌要做灭菌前后力学/松弛对比；EO 要控残留与湿度；包装内控湿。

### 3.4 电偶腐蚀：施夹器是个隐患
Zn/Mg 相对于不锈钢、钛合金是**阳极**。夹持、成形、递送过程中与金属器械接触，在有体液/生理盐水的条件下会形成电偶，局部腐蚀显著加速。
**对策**：施夹器接触部位绝缘（聚合物衬套/涂层）；明确"一次性使用"；做"与预期接触器械组合"的腐蚀试验；洁净度控制（残留金属屑）。

### 3.5 第二相是双刃剑
Zn-Mg 系：Mg 在 Zn 中的**最大固溶度仅约 0.1 wt%**（Zn-Mg 相图，共晶约 364 ℃ / 3 wt% Mg）。超过固溶限就会出现 Mg₂Zn₁₁ / MgZn₂ 等第二相，与基体构成微电偶 → 点蚀、降解不均、局部 Zn²⁺ 浓度尖峰。
**对策**：要么走"低合金固溶"路线（Mg < 0.1 %，靠固溶强化，组织均匀）；要么**有意识地**用第二相提速降解，但必须用降解均匀性和组织反应数据兜住。切忌"加一点 Mg 试试"。

### 3.6 局部 pH 与产物浓度
Zn 腐蚀会使局部环境改变（Zn²⁺ 累积、腐蚀产物层形成）。产物层致密时**反过来抑制降解**，造成"前期快、后期几乎停"的非线性；产物层疏松则局部点蚀。
**对策**：体外降解必须做**长周期（≥ 8–12 周）失重曲线**，不能只报一个平均速率。

### 3.7 缝隙腐蚀
夹臂与组织、夹臂与血痂、两臂之间的缝隙是典型缝隙腐蚀位置，可能先于本体失效。
**对策**：结构上避免窄缝和尖角；做缝隙腐蚀专项评价。

### 3.8 毛刺与锐边
剪断/冲裁 **毛刺** 是断裂源 + 组织刺激源，对可吸收夹尤其致命（边角是应力集中和腐蚀起点）。
**对策**：规定毛刺高度上限；电解抛光/化学抛光；100 % 外观 + 抽样显微检查。

### 3.9 织构各向异性
Zn 是密排六方，挤压/拉拔后形成强织构，**横向与纵向的强度、延伸率、腐蚀行为差别明显**。
**对策**：力学与腐蚀试验都要标注取样方向；把"最不利方向"写进接受准则。

### 3.10 杂质是腐蚀的放大器
Fe、Ni、Cu 在 Zn 中形成阴极相，ppm 级就能显著加速局部腐蚀；Pb、Cd、As、Hg 是毒理红线。**冶炼、坩埚、模具、工具、清洗液**都可能是污染源（尤其铁质坩埚/模具）。
**对策**：专用坩埚（石墨/陶瓷）、专用工具、禁回收料、每炉留样、逐批 ICP-MS 全谱。

## 4. 原材料怎么选

### 4.1 锌（基体）

| 项目 | 建议 |
| --- | --- |
| 纯度 | **Zn 99.995 %（5N）起步，优先 99.999 %（6N）** |
| 参考牌号/标准 | GB/T 470（锌锭）、ASTM B6；植入级建议按 5N/6N 高纯锌采购并附 CoA |
| 形态 | 锭 / 挤压棒 / 预制丝材（丝材可显著降低后续拉拔风险） |
| 供应商 | 有医用/高纯金属供货经验，能提供**熔炼炉号级**追溯；不接受"按纯度报价"的白牌料 |
| 禁忌 | 回收锌、镀锌废料、成分不明的"高纯锌" |

### 4.2 镁（合金元素）

| 项目 | 建议 |
| --- | --- |
| 纯度 | **Mg ≥ 99.95 %**（GB/T 3499 原生镁锭，Mg9995 及以上） |
| 关键杂质 | 氧化物/熔剂夹杂、Fe、Ni、Cu；表面氧化皮必须去除后再入炉 |
| 形态 | 锭/屑（屑料比表面积大、易氧化吸潮，慎用） |
| 注意 | Mg 在熔炼温度下极易氧化燃烧，必须保护气氛或真空；不能裸露加入 |

### 4.3 中间合金（推荐）

直接加纯 Mg 到 Zn 熔体里，**Mg 烧损大、成分波动大**。建议用 **Zn-5 % Mg 或 Zn-10 % Mg 中间合金**（自制或定制），先做小批验证烧损率与均匀性。中间合金本身也要控杂质谱。

### 4.4 建议的杂质内控目标

> 以下为**工程内控建议值**（ppm），不是标准限值；最终须结合降解速率、毒理学评价和 YY/T 1812-2022 的要求确定。

| 元素 | 建议内控上限 | 原因 |
| --- | --- | --- |
| Fe | ≤ 20–50 | 强阴极相，显著加速腐蚀 |
| Ni | ≤ 5–10 | 强阴极相，且致敏/毒性 |
| Cu | ≤ 20–50 | 阴极相，加速腐蚀 |
| Pb | ≤ 10 | 毒性（神经/肾），法规红线 |
| Cd | ≤ 5–10 | 毒性/致癌，法规红线 |
| As / Hg | ≤ 3–5 | 毒性红线 |
| Si / Al | 按工艺控 | Al 有神经毒性争议，尽量低 |
| O（氧含量） | 越低越好 | 氧化物夹杂 → 点蚀起点与疲劳源 |

### 4.5 供应商与入厂检验

**资质**：ISO 13485（或等同）+ ISO 9001；能签质量协议、变更通知（PCN）；不接受"只给一张成分单"。

**每批必检**：
- 化学成分：ICP-MS / ICP-OES 全谱（含痕量元素），对照 CoA 复检；
- 氧/氮/氢含量（惰性气体熔融法，视需要）；
- 金相：晶粒度、第二相体积分数与分布、夹杂物评级；
- 力学：拉伸（纵向 + 横向）、硬度；
- 表面：氧化、油污、裂纹、折叠。

**留样与追溯**：每熔炼炉号留样 ≥ 产品全生命周期 + 2 年；从炉号 → 棒/丝批号 → 成品批号全程可追溯。

**变更控制**：换供应商、换熔炼炉、换热加工工艺都必须重新做**降解 + 力学 + 生物相容性**的部分再确认，不能只做成分复检。

## 5. 工艺路线与关键控制点

```
高纯 Zn + Zn-Mg 中间合金
        │  熔炼（真空/保护气氛，控 Mg 烧损）
        ▼
   铸锭 / 连铸棒  ──► 均匀化退火（溶解第二相、消除偏析）
        │
        ▼
   热挤压（棒/丝/带坯）
        │
        ▼
   冷拉拔 / 冷轧（多道次 + 中间退火）
        │
        ▼
   矫直 → 冲裁/线成形/弯折（夹臂几何）
        │
        ▼
   去应力退火（低温，控晶粒）→ 电解/化学抛光 → 超声清洗 → 钝化（如需）
        │
        ▼
   灭菌（EO / γ，需验证）→ 惰性气氛 + 干燥剂包装 → 有效期验证
```

| 工序 | 关键参数 | 主要风险 |
| --- | --- | --- |
| 熔炼 | 温度、保护气氛、Mg 加入方式、静置/除气、过滤 | Mg 烧损、氧化物夹杂、成分不均、坩埚污染（Fe） |
| 铸造 | 冷却速率、模温、浇注 | 缩孔、气孔、晶粒粗大、偏析 |
| 均匀化 | 温度/时间（低于共晶温度） | 过烧、晶粒粗化、第二相残留 |
| 热挤压 | 温度、挤压比、速度、润滑 | 织构过强、表面开裂、心部缺陷 |
| 冷拉/冷轧 | 道次变形量、中间退火 | 加工硬化开裂、残余应力、表面损伤 |
| 成形/冲裁 | 间隙、模具磨损、毛刺 | 毛刺、微裂纹、尺寸漂移 |
| 去应力退火 | 低温 + 短时（防再结晶长大） | 过度软化 → 夹持力不足 |
| 抛光/清洗 | 电解液配方、时间、漂洗水质 | 过腐蚀、氢/氯残留、点蚀 |
| 灭菌 | 方法 + 剂量/温度/湿度 | 力学与松弛性能漂移、表面腐蚀 |
| 包装 | 惰性气体、湿度、密封完整性 | 储运期受潮腐蚀 |

## 6. 必须做的测试清单

### 6.1 材料理化
- 化学成分（ICP-OES/MS，痕量元素全谱）
- 显微组织：金相、SEM/EDS、EBSD（晶粒与织构）、第二相定量
- 力学：拉伸（GB/T 228.1 / ASTM E8，纵横向）、弯曲、显微硬度、**缺口拉伸**
- 弹性/回弹：弯曲回弹角、弹性极限
- **37 ℃ 应力松弛 / 蠕变**（选材一级指标）
- 表面：粗糙度、氧化层厚度、残余应力（XRD）、毛刺

### 6.2 降解
- 体外浸泡：HBSS / SBF / 模拟体液，37 ℃，pH 7.4，**≥ 8–12 周**
  - 失重法 + 析氢法 + 电化学（极化曲线、EIS）+ 产物 XRD/FTIR 表征
  - 参 ASTM F3268（可吸收金属体外降解测试指南）
- 体内：兔/猪（血管结扎或软组织植入），观察降解速率、产物分布、局部组织反应、氢气腔
- 缝隙腐蚀、电偶腐蚀（与施夹器材料组合）

### 6.3 生物学（GB/T 16886 系列 ≡ ISO 10993）
- 细胞毒性（-5）、致敏/刺激（-10，含降解产物）、植入后局部反应（-6，亚慢性）、
  全身毒性（-11）、遗传毒性（-3）、降解产物毒理评估
- **Zn²⁺ 专项**：局部浓度与全身暴露量评估（Zn 是必需元素，JECFA 的 PMTDI 参考值约 1 mg/kg 体重/日，植入物贡献需单独算）

### 6.4 产品级
- 闭合/夹持力及其衰减（37 ℃、模拟体液浸泡 7/14/28 天）
- 张开-释放循环、疲劳（如适用）
- 影像可见性、MRI 兼容性（如宣称）
- 灭菌验证（EN ISO 11135 / 11137 / 17665）、无菌、EO 残留
- 包装完整性（ASTM F1929 / F88）与加速老化（ASTM F1980）
- 有效期与运输模拟

## 7. 法规路径（中国，简介）

- **分类**：可吸收金属闭合夹通常按 **III 类无源植入器械**管理，需做全面生物学评价与临床评价。
- **参考标准/文件**：
  - **YY/T 1812-2022《可降解生物医用金属材料理化特性表征》** — 可降解金属材料理化表征的核心行业标准（[标准信息](https://www.cssn.net.cn/cssn/productDetail/3d56c30ea8a723988bee35f62436f37d)）
  - **《可降解镁金属骨科植入物注册技术审查指导原则（征求意见稿）》** — 虽然是骨科、镁基，但降解评价、产物评价、动物实验思路可直接参照（[原文](https://www.cmdi.org.cn/zx_4/xyzl/202101/P020210124642262315414.docx)）
  - GB/T 16886 系列（≡ ISO 10993）
  - ASTM F3268（体外降解测试）
- **差异化**：若为国内首创的锌基可吸收夹，可评估**创新医疗器械特别审查程序**（可显著缩短审评时间，但要求 originality 论证充分）。
- **关注动态**：国内已有可降解金属闭合夹获批的先例（如可降解镁金属闭合夹获批上市的公开报道：[CIO 报道](https://www.ciopharma.com/supervise/35620)），可作为同品种比对的参考路径——但材料体系不同，不能直接套用。

## 8. 如果从零开始，先做这五件事

1. **写清临床需求**：目标适应症（血管/胆管/软组织）、期望保持时间、期望完全吸收时间、是否需要影像可见。
2. **定体系**：按第 1 节表格二选一（或两条并行做小试）。
3. **选材并锁杂质谱**：按 4.1–4.4 找 2 家供应商，各要 3 批 CoA + 实测，做**腐蚀速率对比**（这比强度对比更关键）。
4. **做三项筛选试验**：37 ℃ 应力松弛、8 周长周期降解曲线、与施夹器材料的电偶腐蚀。这三项能淘汰掉大部分候选。
5. **再谈结构与灭菌**：结构定型后，灭菌方式必须与材料一起验证，不能后补。

## 9. 需要你确认的信息

写这份文档时我按"通用可吸收金属夹"来写，以下几项会显著改变建议：

- [ ] 基体是 **Zn 基** 还是 **Mg 基**（或两者都在评估）？
- [ ] 适应症：血管结扎 / 胆管 / 软组织 / 其他？
- [ ] 期望保持夹持力的时间（2 周 / 4 周 / 8 周）？
- [ ] 期望完全吸收时间（3 个月 / 6 个月 / 12 个月）？
- [ ] 现有工艺条件（是否有真空熔炼、挤压、拉拔能力；还是找代工）？
- [ ] 灭菌方式是否已锁定？
- [ ] 目标市场（中国 NMPA / CE / FDA），这决定生物学评价和临床路径的工作量。
