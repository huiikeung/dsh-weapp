# 小程序使用说明

面向使用者的简要说明，覆盖配对、对话、设置与公网访问。

## 一、首次配对

1. 在电脑上安装并启用 `dsh-plugin-weapp-gateway` 插件（DSH 桌面端：插件 → 添加插件）。
2. 打开「设置 → 移动设备」，选择小程序中继连接方式并生成配对二维码。
3. 小程序首页点左上角品牌区打开侧栏，或点右上角设备按钮：
   - **扫描二维码**：直接扫电脑上的配对码
   - **手动输入配对信息**：粘贴 Base64URL 配对字符串
   - **配置引导**：不清楚流程时按引导页三步操作（电脑端准备 → 扫码配对）
4. 连接成功后，首页会显示当前主机名称与在线状态。

## 二、对话

- 首页点「新建会话」或最近会话进入对话页。
- 顶部：返回、会话标题、连接状态与模式标签、右上角「更多」。
- 第二行：协作入口、对话/轨迹切换、更多菜单。
- 底部输入框可发送文字、图片和文件；运行中会显示「正在分析 / 执行」等工作过程，完成后折叠为「已完成，用时 N 秒」。
- 轨迹页可查看每次工具调用的参数、结果、Token 与耗时。

## 三、模型与权限

进入「首页右上角 → 会话设置」：

- **Agent 预设**：标准 / 代码 / 极简等，当前项带 ✓
- **默认模型**：按供应商分组，选中模型后可继续选择「思考强度」（低 / 中 / 高）
- **权限**：只读 / 工作区写入 / 完全访问
- 修改只影响之后新建的会话，运行中的会话保持原有配置。

## 四、设置

左侧栏 → 设置：

- **外观**：界面（跟随微信 / 浅色 / 深色）、语言文字、字号
- **节点管理**：查看已配对节点、在线状态、编辑与批量删除
- **公网访问**：公网 ID、有效期、分享邀请
- **微信身份**：识别当前微信、绑定管理员
- **管理员**：兑换码管理、发布公告
- **功能**：插件管理、定时任务、诊断信息、清理缓存
- **关于**：当前版本、要求网关版本、开发者公告、隐私政策

所有设置项都使用底部弹窗，右上角为「关闭」按钮。

## 五、公网访问

1. 在设置 → 公网访问中查看当前有效期（开通后显示到期时间）。
2. **分享**：生成限时邀请，好友首次有效打开后自动增加公网时长。
3. **兑换续期**：输入管理员发放的兑换码，立即延长有效期。
4. 管理员可生成兑换码（3/7/30/180/365 天，1/5/20 次），复制分发；可停用或删除。
5. 公网只影响远程访问，局域网直连不受影响，也不消耗公网时长。

## 六、常见问题

| 现象 | 处理 |
|---|---|
| 首页一直显示未连接 | 检查电脑端插件是否运行、是否在同一网络；公网访问需先兑换有效期 |
| 旧会话打开空白 | 下拉刷新或重新进入会话；仍失败时用「设置 → 诊断信息」查看连接状态 |
| 页面空白/打不开 | 多为预览包过旧或包体超限，重新扫码或联系开发者重新上传 |
| 想让手机停止连接 | 设置 → 节点管理 → 点击节点 → 断开连接；或「忘记此设备」清除本机凭据 |

## 七、开发者命令

```bash
# 编译预览（生成二维码）
node scripts/stamp-build.cjs
/Applications/wechatwebdevtools.app/Contents/MacOS/cli cache --project . --clean compile
/Applications/wechatwebdevtools.app/Contents/MacOS/cli preview --project . \
  --qr-format image --qr-output ./preview-qr.png

# 上传开发版
/Applications/wechatwebdevtools.app/Contents/MacOS/cli upload --project . -v 0.9.13 -d "说明"

# 全量测试
for f in tests/*.test.js; do node "$f"; done
```
